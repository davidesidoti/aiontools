# AionTools Polish Plan — Data, Texts, UX and Accessibility

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the minor issues deferred by the reviews of plans 1, 3 and 4 that users can see. The user picked two groups:
- **Data and texts:** broken guide links, wrong plurals and wording, a missing mode, uncorrected skill names in equip effects, a raw URL used as a link label.
- **UX and accessibility:** palette keystrokes lost, palette matching on internal ids, no undo when removing a character, a misleading pip label, `aria-current` on parent sections, a cramped "Impostazioni" in the bottom nav, a misaligned build header, an Asmodian accent flash, and a repeated toast.

The sync and import-robustness groups were not selected and stay deferred.

**Architecture:** Small, independent fixes inside the existing structure. There are no new libraries and no schema changes.

**Spec:** `docs/superpowers/specs/2026-10-13-aiontools-design.md`. The deferred items come from the final-review sections of plans 1, 3 and 4.

**Branch:** `feat/polish`, created from `main` at `97797be` (PRs #1–#4 merged).

4. **Pip labels must describe what a click does:** the last lit pip removes one. Task 3 unit test.

// "page" only on the exact page; a parent section gets "true" (WAI-ARIA), so screen readers don't announce two current pages.
export function navAriaCurrent(pathname: string, href: string): "page" | "true" | undefined {
  if (pathname === href) return "page";
  return isNavActive(pathname, href) ? "true" : undefined;
}
