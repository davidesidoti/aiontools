# AionTools Plan 2 — Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let one person use the same progress on several devices without a login. An anonymous sync code points at a copy of `UserData` stored in Upstash Redis. That copy is kept in step with localStorage through debounced pushes, pulls on load and on tab focus, and an explicit dialog when two devices conflict. This plan also fixes three deferred data-safety minors from plan 1.

**Architecture:**
- **Server:** a pure handler, `handleSync(req, deps)`, holds all validation, rate limiting and conflict logic. It has unit tests against an in-memory store. The route `src/app/api/sync/route.ts` only wires the real dependencies: Upstash Redis and `@upstash/ratelimit`, or an in-memory store when `SYNC_MEMORY_STORE=1` (local dev and e2e only).
- **Client:** a thin fetch wrapper (`sync-client.ts`) maps HTTP results to typed outcomes. A Zustand sync engine (`sync-store.ts`) does a three-way compare between local, remote and `base` (the last version synced). The engine's tests route `fetch` into the real handler, so they cover the full round trip.
- **Storage:** localStorage stays the primary store. The sync code lives under its own key, `aiontools:sync`, and never inside `UserData`, so an exported JSON file never leaks it.

**Tech Stack:** Next.js 16 route handlers, `@upstash/redis`, `@upstash/ratelimit`, `@scure/bip39` (its English wordlist), Zod 4, Zustand 5, Vitest 5, and Playwright. Everything else is as in plan 1.

**Spec:** `docs/superpowers/specs/2026-10-13-aiontools-design.md`, section 5 (Sync) and section 7 (Error handling).

**Branch:** `feat/plan2-sync`, created from `feat/plan1-foundation-checklist` because PR #1 is not merged yet. Open the PR against `feat/plan1-foundation-checklist`. If #1 has merged by then, open it against `main` instead.

### Deliberate deviations from the spec

| Spec | Plan 2 | Why |
|---|---|---|
| `POST /api/sync` takes `{ data }` and returns `{ code }` | The same, and it returns `201` | `201` is the standard "created" status. |
| `PUT` returns 200 or 409 | It also returns `404` when the code doesn't exist | A client must not be able to create a code it chose itself. Only `POST` creates codes. |
| The sync code's location isn't specified | The code is stored in localStorage under `aiontools:sync`, outside `UserData` | Export files and the synced copy never contain the code. |
| Errors are 400, 413 and 429 | The handler also returns `503 { error: "not_configured" }` when no Upstash env is set | The app keeps working locally, and the client shows "server not responding". |

## Global Constraints

Everything in plan 1's Global Constraints still applies. On top of that:

**The code**
- Format: three BIP39 English words and 4 digits, joined with `-`, matching `^[a-z]{3,8}(-[a-z]{3,8}){2}-\d{4}$`.
- It is generated on the server with a CSPRNG and rejection sampling.
- Input is normalized with `trim().toLowerCase()`.

**Transport**
- The code travels only in the `x-sync-code` request header. It never appears in a URL, a query string or a log line: no `console.*` anywhere in the sync code path.

**Storage and limits**
- Redis key: `sync:{code}`. TTL: 15,552,000 s (180 days), refreshed on every write. Values are stored as raw JSON strings, with `automaticDeserialization: false`.
- Body limit: 65,536 bytes, otherwise `413 { error: "too_large" }`.
- Rate limit: 30 requests per minute per IP (the first `x-forwarded-for` entry), otherwise `429 { error: "rate_limited" }`.
- Every handler response carries `cache-control: no-store`.

**Error bodies**

| Status | Body |
|---|---|
| 400 | `invalid_code`, `invalid_json` or `invalid_data` |
| 404 | `not_found` |
| 405 | `method_not_allowed` |
| 503 | `not_configured` or `code_exhausted` |

**Versioning rules**
- `updatedAt` is bumped only by user edits through `useUserStore.update`.
- Data that arrives from sync goes through `replaceData`, which never bumps `updatedAt`.
- `base` is always the `updatedAt` of the last copy both sides agreed on.

**Timing**
- Pushes are debounced by 2,000 ms.
- After a network, server or rate-limit failure, retries happen after 5 s, then 15 s, then every 60 s.

**Environment variables**
- Production reads `UPSTASH_REDIS_REST_URL`/`UPSTASH_REDIS_REST_TOKEN`, falling back to `KV_REST_API_URL`/`KV_REST_API_TOKEN` (the names the Vercel Marketplace may inject).
- `SYNC_MEMORY_STORE=1` must never be set in production.

## Review Focus

These are the input classes most likely to hurt a real user. Each line names the test that pins it down.

1. **Two devices edit while offline, then both come online.** A conflict dialog appears and neither copy is silently overwritten. Tests: Task 6, "concurrent edits on two devices raise a conflict…" and both resolution tests.
2. **Two tabs in the same browser both push the same data.** This must not raise a false conflict: when the remote copy equals the local one, the engine settles silently. Test: Task 6, "a remote copy identical to local settles without a conflict".
3. **A code typed with spaces or capitals, or a malformed code.** The first is normalized. The second is rejected before any request is sent. Tests: Task 2 (normalize and regex) and Task 6 ("connect … adopts the cloud copy" with an uppercase, padded code, and "connect rejects a malformed code…").
4. **The cloud copy expired or was deleted while a device was still connected.** The push gets 404, the status shows `notFound`, and local data is kept. Test: Task 6, "cloud data gone…".
5. **Upstash is not configured, or the network is down.** The API answers 503 and the client reports a server or network error. The app keeps working from localStorage. Tests: Task 4 (`getSyncDeps` returns null without env), Task 5 (503 maps to `server`, a rejected fetch maps to `network`) and Task 6 ("network failure marks offline…").

```ts
export function setRegion(data: UserData, region: RegionId, now: Date): UserData {
  if (region === data.settings.region) return data;

    new Date(Math.max(new Date(current).getTime(), lastResetAt(now, region, period).getTime())).toISOString();

    settings: { ...data.settings, region },
    checklist: { ...data.checklist, lastDaily: keep(data.checklist.lastDaily, "day"), lastWeekly: keep(data.checklist.lastWeekly, "week") },
```

```ts
// src/store/user-store.ts
import { create } from "zustand";
import { createDefaultUserData, parseStored, type UserData } from "@/lib/user-data";
import { applyResets } from "@/lib/checklist";
import { ACTIVITIES } from "@/lib/activities";

export const STORAGE_KEY = "aiontools:user-data";

type UserStore = {
  data: UserData;
  hydrated: boolean;
  corrupted: boolean;
  // True when corrupt data could not be backed up: keep it on disk until the user makes an edit.
  persistPaused: boolean;
  hydrate(now?: Date): void;
  update(fn: (d: UserData) => UserData): void;
  tickResets(now?: Date): void;
};

function read(key: string): string | null {
  try {
    return localStorage.getItem(key);
  } catch {
    return null;
  }
}

function write(key: string, value: string): boolean {
  try {
    localStorage.setItem(key, value);
    return true;
  } catch {
    // Storage unavailable or full: keep working in memory.
    return false;
  }
}

export const useUserStore = create<UserStore>()((set, get) => ({
  data: createDefaultUserData(new Date()),
  hydrated: false,
  corrupted: false,
  persistPaused: false,
  hydrate(now = new Date()) {
    const raw = read(STORAGE_KEY);
    const { data, corrupted } = parseStored(raw, now);
    const backedUp = !(corrupted && raw !== null) || write(`aiontools-backup-${now.getTime()}`, raw);
    set({ data: applyResets(data, now, ACTIVITIES), hydrated: true, corrupted, persistPaused: !backedUp });
  },
  update(fn) {
    // Apply any reset that passed since the last tick, so the edit lands in the current window.
    get().tickResets();
    const prev = get().data;
    const next = fn(prev);
    if (next !== prev) set({ data: { ...next, updatedAt: new Date().toISOString() }, persistPaused: false });
  },
  tickResets(now = new Date()) {
    const prev = get().data;
    const next = applyResets(prev, now, ACTIVITIES);
    if (next !== prev) set({ data: next });
  },
}));

useUserStore.subscribe((state, prev) => {
  if (state.hydrated && !state.persistPaused && state.data !== prev.data) write(STORAGE_KEY, JSON.stringify(state.data));
});

// Another tab saved: reload so this tab's stale state never overwrites it.
if (typeof window !== "undefined") {
  window.addEventListener("storage", (e) => {
    if (e.key === STORAGE_KEY && useUserStore.getState().hydrated) useUserStore.getState().hydrate();
  });
}
```

```ts
// src/lib/sync-code.ts
import { wordlist } from "@scure/bip39/wordlists/english.js";

export const SYNC_CODE_RE = /^[a-z]{3,8}(-[a-z]{3,8}){2}-\d{4}$/;

// Unbiased integer in [0, n) from the platform CSPRNG (rejection sampling).
function secureRandom(n: number): number {
  const buf = new Uint32Array(1);
  const limit = Math.floor(2 ** 32 / n) * n;
  do crypto.getRandomValues(buf);
  while (buf[0] >= limit);
  return buf[0] % n;
}

export function generateSyncCode(rand: (n: number) => number = secureRandom): string {
  const word = () => wordlist[rand(wordlist.length)];
  return `${word()}-${word()}-${word()}-${String(rand(10_000)).padStart(4, "0")}`;
}

export function normalizeSyncCode(input: string): string {
  return input.trim().toLowerCase();
}
```

```ts
// src/lib/server/sync-store.ts
export interface SyncStore {
  get(code: string): Promise<string | null>;
  set(code: string, value: string): Promise<void>;
  del(code: string): Promise<void>;
}

/** Resolves true when the request is allowed. */
export interface RateLimiter {
  limit(key: string): Promise<boolean>;
}

export const SYNC_TTL_SECONDS = 180 * 24 * 60 * 60;

// shortcut: in-process Map without TTL — for tests, local dev and e2e only; production uses Upstash.
export function createMemoryStore(): SyncStore {
  const m = new Map<string, string>();
  return {
    async get(code) {
      return m.get(code) ?? null;
    },
    async set(code, value) {
      m.set(code, value);
    },
    async del(code) {
```

```ts
// src/lib/server/sync-handler.ts
import { z } from "zod";
import { UserDataSchema } from "@/lib/user-data";
import { SYNC_CODE_RE } from "@/lib/sync-code";
import type { RateLimiter, SyncStore } from "./sync-store";

export const MAX_BODY_BYTES = 65_536;

export type SyncDeps = { store: SyncStore; limiter: RateLimiter; generateCode: () => string };

const PostBody = z.object({ data: UserDataSchema });
const PutBody = z.object({ data: UserDataSchema, baseUpdatedAt: z.iso.datetime() });

const json = (body: unknown, status = 200) => Response.json(body, { status, headers: { "cache-control": "no-store" } });
const fail = (status: number, error: string) => json({ error }, status);

async function readJson(req: Request): Promise<{ ok: true; value: unknown } | { ok: false; res: Response }> {
  if (Number(req.headers.get("content-length") ?? 0) > MAX_BODY_BYTES) return { ok: false, res: fail(413, "too_large") };
  const text = await req.text();
  if (new TextEncoder().encode(text).length > MAX_BODY_BYTES) return { ok: false, res: fail(413, "too_large") };
  try {
    return { ok: true, value: JSON.parse(text) };
  } catch {
    return { ok: false, res: fail(400, "invalid_json") };
  }
}

export async function handleSync(req: Request, deps: SyncDeps): Promise<Response> {
  const ip = req.headers.get("x-forwarded-for")?.split(",")[0]?.trim() || "unknown";
  if (!(await deps.limiter.limit(ip))) return fail(429, "rate_limited");

  if (req.method === "POST") {
    const body = await readJson(req);
    if (!body.ok) return body.res;
    const parsed = PostBody.safeParse(body.value);
    if (!parsed.success) return fail(400, "invalid_data");
    for (let attempt = 0; attempt < 3; attempt++) {
      const code = deps.generateCode();
      if ((await deps.store.get(code)) !== null) continue;
      await deps.store.set(code, JSON.stringify(parsed.data.data));
      return json({ code }, 201);
    }
    return fail(503, "code_exhausted");
  }

  const code = req.headers.get("x-sync-code") ?? "";
  if (!SYNC_CODE_RE.test(code)) return fail(400, "invalid_code");

  switch (req.method) {
    case "GET": {
      const raw = await deps.store.get(code);
      return raw === null ? fail(404, "not_found") : json({ data: JSON.parse(raw) });
    }
    case "PUT": {
      const body = await readJson(req);
      if (!body.ok) return body.res;
      const parsed = PutBody.safeParse(body.value);
      if (!parsed.success) return fail(400, "invalid_data");
      const raw = await deps.store.get(code);
      if (raw === null) return fail(404, "not_found");
      const stored = JSON.parse(raw) as { updatedAt: string };
      if (new Date(stored.updatedAt) > new Date(parsed.data.baseUpdatedAt)) return json({ data: JSON.parse(raw) }, 409);
      await deps.store.set(code, JSON.stringify(parsed.data.data));
      return json({ updatedAt: parsed.data.data.updatedAt });
    }
    case "DELETE":
      await deps.store.del(code);
      return new Response(null, { status: 204, headers: { "cache-control": "no-store" } });
    default:
      return fail(405, "method_not_allowed");
  }
}
```

```ts
  if (cached) return cached;
```

```ts
// src/lib/sync-client.ts
import { UserDataSchema, type UserData } from "./user-data";

export type SyncError = "invalidCode" | "notFound" | "rateLimited" | "network" | "server";
export type SyncResult<T> = { ok: true; value: T } | { ok: false; error: SyncError };
export type PushResult = SyncResult<{ updatedAt: string }> | { ok: false; error: "conflict"; remote: UserData };

const ENDPOINT = "/api/sync";
type Raw = { status: number; json: unknown } | null;

async function call(method: string, code?: string, body?: unknown): Promise<Raw> {
  try {
    const res = await fetch(ENDPOINT, {
      method,
      cache: "no-store",
      headers: { "content-type": "application/json", ...(code && { "x-sync-code": code }) },
      body: body === undefined ? undefined : JSON.stringify(body),
    });
    const json = res.status === 204 ? null : await res.json().catch(() => null);
    return { status: res.status, json };
  } catch {
    return null;
  }
}

function toError(r: Raw): SyncError {
  if (!r) return "network";
  if (r.status === 429) return "rateLimited";
  if (r.status === 404) return "notFound";
  if (r.status === 400 && (r.json as { error?: string } | null)?.error === "invalid_code") return "invalidCode";
  return "server";
}

function parseData(json: unknown): UserData | null {
  const r = UserDataSchema.safeParse((json as { data?: unknown } | null)?.data);
  return r.success ? r.data : null;
}

export async function createRemote(data: UserData): Promise<SyncResult<{ code: string }>> {
  const r = await call("POST", undefined, { data });
  const code = (r?.json as { code?: unknown } | null)?.code;
  return r?.status === 201 && typeof code === "string" ? { ok: true, value: { code } } : { ok: false, error: toError(r) };
}

export async function fetchRemote(code: string): Promise<SyncResult<UserData>> {
  const r = await call("GET", code);
  if (!r || r.status !== 200) return { ok: false, error: toError(r) };
  const data = parseData(r.json);
  return data ? { ok: true, value: data } : { ok: false, error: "server" };
}

export async function pushRemote(code: string, data: UserData, baseUpdatedAt: string): Promise<PushResult> {
  const r = await call("PUT", code, { data, baseUpdatedAt });
  if (r?.status === 200) return { ok: true, value: { updatedAt: data.updatedAt } };
  if (r?.status === 409) {
    const remote = parseData(r.json);
    if (remote) return { ok: false, error: "conflict", remote };
  }
  return { ok: false, error: toError(r) };
}

export async function deleteRemote(code: string): Promise<SyncResult<null>> {
  const r = await call("DELETE", code);
  return r?.status === 204 ? { ok: true, value: null } : { ok: false, error: toError(r) };
}
```

```ts
// src/store/sync-store.ts
import { create } from "zustand";
import { useUserStore } from "./user-store";
import type { UserData } from "@/lib/user-data";
import { normalizeSyncCode, SYNC_CODE_RE } from "@/lib/sync-code";
import { createRemote, deleteRemote, fetchRemote, pushRemote, type SyncError } from "@/lib/sync-client";

export const SYNC_KEY = "aiontools:sync";
export const PUSH_DELAY_MS = 2_000;
const RETRY_MS = [5_000, 15_000, 60_000];

export type SyncStatus = "off" | "synced" | "pending" | "offline" | "error";

type SyncState = {
  code: string | null;
  base: string | null; // updatedAt of the last copy both sides agreed on
  status: SyncStatus;
  error: SyncError | null;
  conflict: UserData | null;
  start(): void;
  createCode(): Promise<void>;
  connect(input: string): Promise<boolean>;
  disconnect(): void;
  deleteCloud(): Promise<void>;
  pull(): Promise<void>;
  push(): Promise<void>;
  resolveConflict(choice: "cloud" | "overwrite"): Promise<void>;
};

let pushTimer: ReturnType<typeof setTimeout> | undefined;
let retryTimer: ReturnType<typeof setTimeout> | undefined;
let retries = 0;
let started = false;

function persist(code: string | null, base: string | null) {
  try {
    if (code) localStorage.setItem(SYNC_KEY, JSON.stringify({ code, base }));
    else localStorage.removeItem(SYNC_KEY);
  } catch {
    // Storage unavailable: sync still works for this session.
  }
}

function readPersisted(): { code: string; base: string | null } | null {
  try {
    const v = JSON.parse(localStorage.getItem(SYNC_KEY) ?? "null");
    if (!v || typeof v.code !== "string" || !SYNC_CODE_RE.test(v.code)) return null;
    return { code: v.code, base: typeof v.base === "string" ? v.base : null };
  } catch {
    return null;
  }
}

function schedulePush() {
  clearTimeout(pushTimer);
  pushTimer = setTimeout(() => void useSyncStore.getState().push(), PUSH_DELAY_MS);
}

export const useSyncStore = create<SyncState>()((set, get) => {
  const settle = (base: string) => {
    retries = 0;
    clearTimeout(retryTimer);
    set({ base, status: "synced", error: null });
    persist(get().code, base);
  };

  // Set base first so the user-store subscriber does not treat the incoming copy as a local edit.
  const applyRemote = (remote: UserData) => {
    settle(remote.updatedAt);
    useUserStore.getState().replaceData(remote);
  };

  const fail = (error: SyncError) => {
    set({ status: error === "network" ? "offline" : "error", error });
    if (error === "network" || error === "server" || error === "rateLimited") {
      clearTimeout(retryTimer);
      retryTimer = setTimeout(() => void get().pull(), RETRY_MS[Math.min(retries++, RETRY_MS.length - 1)]);
    }
  };

  // Three-way compare of local and remote against base.
  const reconcile = (remote: UserData) => {
    const local = useUserStore.getState().data;
    if (remote.updatedAt === local.updatedAt) return settle(remote.updatedAt);
    const { base } = get();
    const remoteChanged = remote.updatedAt !== base;
    const localChanged = local.updatedAt !== base;
    if (remoteChanged && localChanged) return set({ conflict: remote, status: "error", error: null });
    if (remoteChanged) return applyRemote(remote);
    void get().push();
  };

  return {
    code: null,
    base: null,
    status: "off",
    error: null,
    conflict: null,

    start() {
      if (started) return;
      started = true;
      const saved = readPersisted();
      if (saved) {
        set({ code: saved.code, base: saved.base, status: "pending" });
        void get().pull();
      }
      document.addEventListener("visibilitychange", () => {
        if (document.visibilityState === "visible") void get().pull();
      });
      // Another tab connected, synced or disconnected: adopt its code and base.
      window.addEventListener("storage", (e) => {
        if (e.key !== SYNC_KEY) return;
        const next = readPersisted();
        if (next) set({ code: next.code, base: next.base });
        else set({ code: null, base: null, status: "off", error: null, conflict: null });
      });
    },

    async createCode() {
      const data = useUserStore.getState().data;
      set({ status: "pending", error: null });
      const r = await createRemote(data);
      if (!r.ok) return fail(r.error);
      set({ code: r.value.code });
      settle(data.updatedAt);
    },

    async connect(input) {
      const code = normalizeSyncCode(input);
      if (!SYNC_CODE_RE.test(code)) {
        set({ error: "invalidCode" });
        return false;
      }
      set({ status: "pending", error: null });
      const r = await fetchRemote(code);
      if (!r.ok) {
        set({ status: get().code ? "error" : "off", error: r.error });
        return false;
      }
      clearTimeout(pushTimer);
      set({ code, conflict: null });
      applyRemote(r.value);
      return true;
    },

    disconnect() {
      clearTimeout(pushTimer);
      clearTimeout(retryTimer);
      retries = 0;
      set({ code: null, base: null, status: "off", error: null, conflict: null });
      persist(null, null);
    },

    async deleteCloud() {
      const { code } = get();
      if (!code) return;
      const r = await deleteRemote(code);
      if (!r.ok) return fail(r.error);
      get().disconnect();
    },

    async pull() {
      const { code, conflict } = get();
      if (!code || conflict) return;
      const r = await fetchRemote(code);
      if (!r.ok) return fail(r.error);
      reconcile(r.value);
    },

    async push() {
      clearTimeout(pushTimer);
      const { code, base, conflict } = get();
      if (!code || conflict) return;
      const sent = useUserStore.getState().data;
      set({ status: "pending" });
      const r = await pushRemote(code, sent, base ?? sent.updatedAt);
      if (r.ok) {
        settle(sent.updatedAt);
        if (useUserStore.getState().data.updatedAt !== sent.updatedAt) schedulePush();
        return;
      }
      if (r.error === "conflict") return reconcile(r.remote);
      fail(r.error);
    },

    async resolveConflict(choice) {
      const remote = get().conflict;
      if (!remote) return;
      set({ conflict: null });
      if (choice === "cloud") return applyRemote(remote);
      set({ base: remote.updatedAt });
      await get().push();
    },
  };
});

// Every user edit (a new updatedAt that isn't the agreed base) schedules a debounced push.
useUserStore.subscribe((state, prev) => {
  const { code, base } = useSyncStore.getState();
  if (!code || state.data.updatedAt === prev.data.updatedAt || state.data.updatedAt === base) return;
  useSyncStore.setState({ status: "pending" });
  schedulePush();
});
```
